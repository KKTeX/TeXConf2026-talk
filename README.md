# リアルタイム TeX プレビュー

TeXConf 2026（2026年11月21日）での KKTeX の発表資料です。

打鍵の瞬間に該当ページだけが変わるリアルタイムプレビューを、TeX の組版が「どこまで局所的で、どこから非局所的か」という切り分けから設計した話です。前半で箱とグルー、行分割、ページビルダ、出力ルーチンを追い、後半でエンジンの設計（行は TeX に組ませ、ページは自前のページビルダで組み直す）を説明しました。
